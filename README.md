# Text Summarization System

## Description

This project automatically generates a short summary from a longer text using Natural Language Processing.

## Technologies Used

- Python
- NLP
- Sumy
- LSA Summarization

## How It Works

1. The user enters a paragraph.
2. The text is divided into sentences.
3. The LSA algorithm analyzes the sentences.
4. The most important sentences are selected.
5. A short summary is displayed.
